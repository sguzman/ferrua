# 📋 GitHub tracking queue

Milestones, phases, atomic tasks and evidence live in [`progress.json`](progress.json) and the generated [`ROADMAP.md`](ROADMAP.md). GitHub issues can mirror these phase-level work queues without replacing the ledger.

- 🌙 [**M0/P0 — Foundation**](https://github.com/sguzman/ferrua/issues/1): README, color, reproducible CI and evidence checking.
- ⚙️ [**M0/P1 — Working interpreter**](https://github.com/sguzman/ferrua/issues/2): Lua CLI modes, REPL, source arguments, sandbox and smoke tests.
- 🗂️ [**M1/P2 — Everyday automation**](https://github.com/sguzman/ferrua/issues/3): JSON, filesystem helpers, process control, Linux releases and setup action.
- 🔩 [**M2/P3 — Independent engine**](https://github.com/sguzman/ferrua/issues/4): Ferrua-owned compiler, register VM and conformance suite.

Acceptance evidence must be attached before flipping a check to passed. Do not list completed tasks at 100% in routine progress reports; see the roadmap for their provenance.

- 🌐 [**M1/P4 — Versioned releases and CI adoption**](https://github.com/sguzman/ferrua/issues/5): signed/versioned distribution and adoption acceptance separate from the verified preview.
