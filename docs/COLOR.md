# 🎨 Ferrua project color

**Identity:** moonlit teal, distinct from the amber Posthorn, periwinkle Typefinch and iron-oxide Rust Age accents.

- Perceptual selection: **OKLCH** `oklch(70% 0.12 186)`
- Approximate OKLab: `L=0.70, a=-0.11934, b=-0.01254`
- sRGB output: **`#15B6A9`** (in gamut)
- Swatch: [`assets/ferrua-color.svg`](../assets/ferrua-color.svg)

The hue blends the lunar identity of Lua and a bright forged-metal feel. The color is an identity accent, not a required code or terminal foreground color. Accessible foreground contrast should be checked separately. It has not been asserted unique across a global registry.
